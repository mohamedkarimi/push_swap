# libft (42 Network)

This project is my personal implementation of **libft**, the first project of the 42 Network curriculum.  
The goal is to create a custom C library by reimplementing standard libc functions and adding useful utility functions.

##About the project

`libft` is a static library (`libft.a`) that can be reused in future C projects.  
It contains reimplemented standard functions as well as additional helpers for strings, memory, and linked lists.

##Functions implemented

The library includes functions from the following categories:

- **Libc functions** (e.g. `ft_strlen`, `ft_memcpy`, `ft_strdup`)
- **String manipulation**
- **Memory management**
- **Character checks and conversions**
- **Linked list utilities** (bonus part)

All functions are written in C and follow the 42 Norm.
